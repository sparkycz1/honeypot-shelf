Import honeypot & company configuration

Paste JSON exported from Honeypots ("Export config (JSON)"). This creates real honeypots and companies directly — it is not the pending-review queue bulk import uses, so it's meant for restoring/migrating already-known configuration, not discovering unknown hosts.

This is a structural export/import, not a credentials backup: it never contains (or restores) a honeypot's password/key material or its pinned SSH host-key fingerprint. A honeypot originally using password authentication is imported with "SSH key" instead (there's nothing to re-import) — its name is called out below so you can revisit its credentials. Every imported honeypot starts with no pinned host key, exactly like a freshly hand-added one — use "Discover key fingerprint" and confirm it before anything connects to it.

A honeypot whose name already exists is skipped, not overwritten — this never changes an existing honeypot's connection details.
